- **The screening report's "Largest vessel" section (#390, spec 0016 T3).** When the design holds a size sweep (`owd envelope`), the screening report gives its answer after "What fits": the largest size that passes the whole reach, with the rule set, the draught and the plan line; a table of the sizes (R_min, bottom width, whether each passes, its stretches); a chart of each size along the reference line; the per-kilometre strip; and the catalogue classes within the largest size. A stale sweep says so. Without a sweep, the section says how to make one. The "Data and limits" box gains "Largest vessel": the banks can set the limit, and how many low-confidence stretches of bank lie along the reference line.
