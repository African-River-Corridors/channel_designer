# Triage labels

The skills speak in terms of five triage roles. This table maps them to the labels in this repo.

| Role | Label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an agent to build |
| `ready-for-human` | `ready-for-human` | Needs a person: a decision, an account, or a release |
| `wontfix` | `wontfix` | Will not be actioned |

The repo also uses `roadmap` and `known issue`.
