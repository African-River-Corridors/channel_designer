- **`owd fits` names a Rule Set and its quality as `owd size` does (#362).** `owd fits design.owd --rule-set pianc-wg141 --set-input se_quality=C` is the answer under PIANC-C, and `--rule-set gb50139 --set-input range_end=strict` the one under CN-conservative. Each `--rule-set` is one more answer. The old names still work with `--ruleset` (and `CN-reduced` has only that form); their answers come first. A Rule Set without its input, or with a value it does not take, is refused with the values it takes.
