- **`vessel-designer` now comes from PyPI.** `pip install open-waterway-designer` takes `vessel-designer>=0.2.5,<0.3` from PyPI, in place of the git tag `v0.2.2`. PyPI refuses a package with a git dependency, so this is what lets OWD itself be published there. `vessel-designer` ships a wheel per platform, so no compiler is needed. Its catalogue grows from 12 vessel classes to 292, with new ids (`CEMT-IV` for `CEMT_IV`); OWD still reads the old ids, so saved studies open as before.
