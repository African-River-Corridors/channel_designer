The checks list has one row for each check an option has (`fits_in_water`, `join_guard` and `no_feasible_line` join `R_min`), and the R_min row says it reads the design line. Each table row has the screening `verdict` and a `verdict_reason` in words, shown under the verdict. For example: "3 infeasible stretches: no line that meets R_min fits in the navigable water; …; the radius stretches read the river's own bends, not the design line".
