Open Waterway Designer

Explore the navigation possibilities of a river.

Give OWD a river and a vessel. It sizes a navigation channel to a named standard, lays design line options through the river as it is, and measures what each one would cut and dredge. Every number cites its source. Every failed check says why.

How OWD works

Screening, not construction

OWD compares options early, before you pay for a design. It does not approve a channel. Check every number against the standard and your own design basis.

Cites its sources

Width, bend widening, bend radius and depth come from a named rule set: PIANC WG 141 qualities A, B and C, or GB 50139. Each value names its clause, table and page.

Shows where it fails

An option that bends tighter than the minimum radius is marked on the map and in the table, with the radius it has and the radius it needs.

Uses the river, not the bank

The route search moves the line sideways where that cuts less ground, while it holds the minimum radius. Where an option leaves the river, the cut is measured, not hidden.

Runs on your computer

The engine is a Rust core with a desktop app, a command line and a Python package. The web app runs the same core in your browser, so what you load stays on your computer. It fetches one thing from the internet: map imagery, for the map view. Terrain comes from a DEM file you supply.

Open and inspectable

Apache 2.0. The code, the rule sets and their sources are in the repository. Read the working, or change it.

A channel in a bend

A river is deep on the outside of a bend and shallow over the point bar on the inside. A navigation channel needs a set depth and width all the way along, and more width in the bends.

Where the bed stands above the channel, it must be dredged. Where the line leaves the river, the bank must be cut. OWD measures both, option by option, so you can see what each line would cost in ground moved.

Four stages

  1. Sizing. Choose a rule set and a vessel class. OWD gives the channel width, depth, bend widening and minimum radius.
  2. Alignment. Load the banks. OWD finds the centreline and lays design line options that the vessel can sail.
  3. Optimise (optional). Weir sites and pool levels, and the least-cost line through each pool. Costs are weights you supply.
  4. Volumes. Dredge and dry cut for each option, station by station, from a DEM. Quantities only; pricing is yours.

Try it now, or install

The web app needs no install. Open the example, or load your own banks and a DEM.

pip install "open-waterway-designer @ git+https://github.com/African-River-Corridors/open-waterway-designer"

Needs Python 3.12 or later and a Rust toolchain, because this builds the core from source. A PyPI release is coming. The desktop app has no release yet: build it from source. Install notes
