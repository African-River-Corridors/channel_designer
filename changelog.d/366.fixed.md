- **No feasible line is no longer a design (#366).** When every bend of the water-aware rolling circle was infeasible, `owd align --method rolling-circle` kept the fallback line with `radius_ok: true`, and `owd volumes` costed it as a design. The option now has a `feasible` check (`ok: false`, note `no feasible line`), which every export, the table and the report list as the failed check `no_feasible_line`. Its screening verdict is `not-navigable`, the volumes stage gives it no volumes, and `owd align` says so and exits with code 1. An infeasible bend now always leaves a stretch on the final line, even when the final line's own checks find none there.
