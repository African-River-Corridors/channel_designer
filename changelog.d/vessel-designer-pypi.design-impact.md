- **The vessel catalogue of `vessel-designer` 0.2.5.** What moved: the design-impact scenarios run every catalogue class, so the Rule Set grid now holds 292 classes under their new ids (`CEMT-IV`, not `CEMT_IV`) in place of 12. No number moved: the eight old classes that have a new id give the same widths, radii and depths, to the last digit, under old and new ids. Classes OWD does not size a channel for (a pusher or a tug alone, a class with no draught, a pushed barge or ATB under GB 50139 alone) are recorded as refusals with OWD's reason. Why: the pin moves from the git tag `v0.2.2` to the PyPI release.
